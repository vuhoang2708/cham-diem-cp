Cloud Pipeline Architecture

vnstock (TCBS API)
  → fetch_ohlcv(symbol, days=90)
  → compute_adx_indicators()      ← pandas-ta ADX(14)
  → compute_rrg_indicators()      ← RS-Ratio/RS-Mom vs VNINDEX benchmark
  → compute_net_buying_proxy()    ← volume-based MCDX proxy
  → scoring.py (same formulas, unchanged)
  → database.py (same schema, unchanged)
⚠️ Lưu ý MCDX: Cloud version dùng volume-based proxy thay cho FireAnt proprietary indicator. Cần liên hệ FireAnt/SSI về data licensing trước Phase 2.
