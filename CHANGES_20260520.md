## 1. `backend/create_apx.py` — viết lại hoàn toàn

**Vấn đề cũ:**
- `FORMULA` dùng raw string với `\r\n` literal → AmiBroker import AFL bị ghi literal `\r\n` vào code → syntax error
- Có `"\n"` trong `fputs()` string → AmiBroker import thành newline thật bên trong string → AFL hỏng
- `FormulaPath` để trống → AmiBroker hiện modal "Can not open formula file" → Python bị block vô hạn
- Dùng `html.escape()` → `>=` thành `&gt;=` nhưng `<` thành `&lt;` → AFL bị encode sai khi AmiBroker đọc lại

**Thay đổi:**
- `AFL_TEMPLATE` là multiline string thật (`"""\..."""`) — không escape, không `\r\n`
- Quadrant logic dùng `NOT rsm_hi` thay vì `rsm < 100` để tránh raw `<` trong XML
- Output AFL một dòng duy nhất với separator `;`: `symbol=X;banker=Y;...;ready=1`
- `ensure_afl()` ghi AFL thật vào `D:\MetakitData\AmibrokerFA\EOD\Formulas\CodexBridge\ag_bridge.afl`
- `FormulaPath` trong APX trỏ đến `CodexBridge\ag_bridge.afl` — luôn có file thật
- `FormulaContent` trong APX là cùng AFL multiline text thật (không escape)
- Output path: `C:/Users/Public/ag_bridge_out.txt`
- APX: `ApplyTo=1` (current symbol), `RangeType=1`, `RangeAmount=1`

## 2. `backend/scraper_amibroker.py` — viết lại hoàn toàn

**Vấn đề cũ:**
- Dùng `ab.Stocks` API để đọc OHLCV rồi tính MCDX/RRG trong Python — không dùng FA_MCDX/FA_RRG thật của FireAnt plugin
- Kết quả không khớp với AmiBroker UI vì công thức proprietary không được replicate đúng

**Thay đổi:**
- Bỏ toàn bộ Python MCDX/RRG calculation
- Flow mới cho mỗi symbol:
  1. Xóa output file cũ (`out_path.unlink(missing_ok=True)`)
  2. `create_apx(symbol)` — tạo APX với `Symbol=<symbol>`
  3. `doc = ab.AnalysisDocs.Open(apx_path)`
  4. `doc.Run(1)` — Exploration mode
  5. Poll `C:\Users\Public\ag_bridge_out.txt` cho đến khi có `ready=1`
  6. Parse `key=value;key=value` → dict
  7. `doc.Close()`
- Timeout 60s per symbol, poll interval 0.5s
- `_build_result()` convert parsed strings → typed floats/int
- Scoring functions `_score_banker()` và `_score_rrg()` giữ nguyên logic

## Vấn đề còn mở

**Set current symbol trước khi chạy scan:**
- APX có `<Symbol>VCB</Symbol>` nhưng chưa rõ AmiBroker có tự navigate đến symbol đó không
- Nếu AmiBroker vẫn dùng symbol đang active trên UI → cần thêm bước navigate
- Codex retest chạy trên VNINDEX vì đó là current symbol UI lúc đó → `rs_ratio=0`, `rs_mom=0` (VNINDEX là benchmark, không có RRG so với chính nó)
- Cần chạy `test_ami_bridge.py` để xác nhận VCB trả về giá trị khác 0

**Nếu symbol không tự set được qua APX `<Symbol>` tag:**
- Thử `ab.ActiveDocument` hoặc navigate qua `ab.Stocks`
- Hoặc dùng universe/watchlist filter thay vì `ApplyTo=1`
